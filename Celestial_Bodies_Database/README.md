##  Getting Started

### Prerequisites
Make sure you have [PostgreSQL](https://postgresql.org) installed on your system before running this project.

### Installation & Setup
1. Open your terminal and navigate to the project directory containing `universe.sql`.
2. Run the following command to import the database:

   ```bash
   psql -U postgres < universe.sql
   ```

#### You are good to go, explore the database and modify it to your liking.
